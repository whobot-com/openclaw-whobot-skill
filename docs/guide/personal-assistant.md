# 个人助理

个人助理（Personal Agent）面向个人，替你给别人打电话办事，如餐厅订位；现在能办哪些事，以系统返回的个人助理为准。它是单独的一套用法，不走[体验通话](try-a-call.md)里的标杆试打；标杆列表里也能看到同一个员工，那里只是普通体验，不会替你打给别人。

## 你可以这样说

- 帮我给这家店打电话订个位。
- 用个人助理替我打个电话问一下。
- 个人助理还剩多少分钟？给个人助理充点分钟。
- 个人助理的钱怎么退？代拨记录和录音在哪看？

## 会发生什么

1. Skill 按你要办的事选个人助理；现在还不支持的事会如实说明，不拿别的个人助理凑。
2. 本次对话第一次用个人助理时，Skill 先介绍它现在能办的事、怎么计费和网站地址，同时问办这件事需要的信息。
3. 要收集哪些信息按个人助理的说明书来，缺的一次问完，日期时间换算成具体日期和时刻。你在网站设置里填过的信息（如回电号码，没设置时就是登录手机号）会自动带上，不再追问；确认卡上能看到，要改直接说。
4. 系统返回**确认卡**，你确认后直接拨出，不需要验证码，也不会打给你本人。余额不足 5 分钟时，确认卡会建议先充值。
5. Skill 自动等待结果，结束后给出接听情况、通话时长、通话摘要、完整文字对话和录音；接通的电话还会给出网站上这一单的记录链接。没打通会如实说明，只建议稍后再试，不会自动重拨。余额不多时，讲完结果会问你要不要现在充值，不替你决定。

## 代拨号码

号码从哪来，按个人助理的说明书：有的由系统按名称和区域查号，有的要你给号码。

- 系统查到多家时，用选择卡让你选。
- 系统查不到或暂时查不了时，Skill 转述提示，再按说明书处理。
- 号码是 Skill 自己查到的：会告诉你号码和来源，你确认后再拨。
- 不编号码、不猜号码，不用来源不明的号码；换一个号码再打之前会先问你。

## 计费与次数

- 接通才计时，按通话时长扣个人助理的分钟（不足 1 分钟按 1 分钟），没接通不扣；新用户送分钟。单价和剩余分钟以确认卡和余额查询的返回为准。
- 登录手机号不限代拨次数；同一个号码每天被代拨的次数有上限，用完时 Skill 只转述，不会换号码或换账号重试。

## 余额与充值

个人助理的分钟按登录手机号单独计，和企业账户余额是两本账，见[账号与余额](account.md#查余额)。

- **查余额**：Skill 告诉你“个人助理还剩 X 分钟”；上次通话超出余额时，会说明欠多少分钟，充值后先抵扣。
- **充值**：代拨时分钟不够或欠费、查余额不足 1 分钟、确认卡或通话结果建议充值而你同意，或你主动要充值时，Skill 用选择卡让你选充值方式：去网站充值、微信支付或支付宝。选微信或支付宝后再选档位（只列充值后够打一通电话的档位），Skill 在对话里给出付款码和付款页链接。
- **到账**：付好后告诉 Skill，它会查是否到账；到账后问你要不要接着发起刚才的代拨，并重新给确认卡。还没到账时等你再说，不会自己反复查。

Skill 不替你选充值方式或档位，不会在你没选时下单，也不会重复下单。

## 网站、记录、退款与发票

个人助理有自己的网站 <https://dingcan.whobot.com/>，用登录呼波特的同一个手机号、短信验证码登录，代拨的电话都能在网站上看到：

- 概览：剩余分钟和最近的代拨记录。
- 订位记录：每通代拨电话的结果、录音和文字对话，可以删除某一单的录音和对话；觉得结果或计费不对，在那条记录里点「结果不对？告诉我们」。
- 钱包：充值（微信、支付宝）、看充值记录、申请退款、看退款进度。
- 设置：打电话时用的信息（如称呼、回电号码、开场白），代拨时会用作默认信息；短信通知、更换手机号、已授权的 AI 助手、导出个人信息和注销账号。

网站上不能发起代拨，代拨在对话里发起。

- **退款**：对话里不能退款，请到网站[钱包页](https://dingcan.whobot.com/app/wallet)点「申请退款」。没用完的充值分钟按充值时的单价原路退回（退到微信零钱一般几分钟到账，退到银行卡 1–3 个工作日）；赠送的分钟不能退；通话进行中不能申请。完整规则见[计费与退款规则](https://dingcan.whobot.com/legal/terms#pricing)。
- **发票**：在网站钱包页点「联系客服」，提供充值订单号（钱包的充值记录里能看到）和开票信息，客服核实后开电子普通发票。

个人助理的充值、退款和发票都在这个网站办理，不走企业管理平台。
