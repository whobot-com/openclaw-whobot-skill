# 找标杆员工

“标杆”是呼波特已经做好、可以直接体验或参考的数字员工，覆盖 30 多个行业。

## 你可以这样说

- 有什么标杆？
- 做口腔诊所到店邀约的，有合适的吗？
- 我们是联通代理，给老用户推套餐，有没有类似的？
- 还有吗？换一批。

## 会发生什么

1. 你还没说需求时，Skill 先说一句能做什么，再用选择卡给出标杆最多的 3 个行业让你挑。
2. 你说了需求，Skill 用你的原话查一次，然后按三件事判断每个标杆合不合适：
   - **打给谁**：同一类人（家长、老学员、新线索、车主、业主、老用户……）；
   - **电话目标**：同一类事（邀约到店、预约试听、加微信、唤醒沉睡客户、回访、续费、当场办理）；
   - **卖什么**：产品同类，或打法能直接借鉴。
3. 默认最多推荐 3 个，第一个最贴近。只说一句为什么，不念整段简介。
4. 选中后再问下一步：**先网页体验（推荐）**，或直接用它做你自己的员工。

## 匹配规则

- 你说过的条件都要对上；说了“打给谁”和“电话目标”时两条都对上才算合适。
- 意思相同就算对上，例如“考证”与“职业教育”，“激活老学员”与“沉睡唤醒”。
- 你的说法和平台行业名不同，会按意思对应：运营商、宽带、流量卡 → 通信；保险、贷款 → 金融；牙科、医美 → 医疗；4S 店、汽修 → 汽车；楼盘、中介 → 房产。
- 宁缺毋滥：同行业但打的人或目标不同，不推荐；没有合适的就直说。

## 没有合适的怎么办

Skill 会照实说没有，并建议用你们的资料或销售录音做一个专属员工，一次问清企业名称、卖什么、打给谁、电话目标。见[创建数字员工](create-agent.md)。
