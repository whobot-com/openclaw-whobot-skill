# 线索外呼

## 前提：员工要先上岗

培训中的员工不能拨打线索，也不会培训完自动开拨。请到[管理平台](https://work.whobot.com/)的员工管理里让它正式上岗：

1. 企业未认证的，先上传营业执照完成企业认证；
2. 上岗时设置好拨打时段；
3. 确保余额或坐席费充足。

培训期间可以先用网页试打。

## 你可以这样说

- 先给我一份表头模板。
- 把这批客户交给它打，只在工作日白天拨。
- 不要去重。 / 按手机号去重最近 30 天。
- 这批线索进度怎么样？
- 暂停这批，明天再恢复。

## 上传前确认

Skill 会把以下内容说清楚，等你明确回复“确认”才上传（这一步没有系统确认卡）：

| 项目 | 说明 |
|---|---|
| 目标员工 | 由哪个员工拨打 |
| 输入来源 | 本地 Excel / JSON 文件、Excel 直链，或你粘贴的 JSON |
| 拨打时段 | 北京时间，例如“工作日 09:00-11:30 14:00-17:30”，或不限时段 |
| 去重 | 是否按手机号去重、去重最近多少天（推荐 30 天），也可以关闭 |
| 费用 | 上传本身不收费，外呼费用按实际使用产生 |

本地 Excel 只检查第一张表的第一行表头：不能为空、不能重复，必须有“电话号码”列。数据行不在本地检查；JSON 和 Excel 直链直接提交。模板里的电话号码列是文本格式，枚举列带下拉。

## 上传之后

- “上传已受理”不等于导入完成，更不等于已开始外呼。Skill 会等一次导入回执，有重复号码被跳过时原样告诉你。
- 问进度时查询线索包：默认看近 30 天，也可以指定“最近 7 天”或起止日期。
- 暂停、恢复先给确认卡。暂停不等于完成。

## 目前不支持

逐个号码的拨打结果、某个客户是否接通、单条录音暂不支持；只能看整包汇总（进度、拨打数、接通数、意向数和累计费用）。
