# 创建数字员工

## 四种起点

| 起点 | 适合 | 说明 |
|---|---|---|
| 参考标杆 | 有贴近的标杆，想改成自己的品牌和产品 | 先检查能否照该标杆生成，能用才继续问企业信息 |
| 通话录音 | 有销售打得好的真实录音 | 效果最好；少于 5 通会建议多传几通，但不强求 |
| 产品资料 | 有介绍、价目表、话术、常见问题 | 没有录音时会先用资料模拟几通对话再生成 |
| 一段业务描述 | 什么材料都没有 | 说清卖什么、打给谁、想让客户做什么即可 |

录音、资料和标杆可以组合：有录音时用录音生成、标杆作参考、资料作企业事实。标杆里的企业名、价格、承诺不会被当成你们企业的事实。

## 你可以这样说

- 用这几段录音做一个我们自己的员工。
- 就按刚才那个标杆做，我们叫「丹丹口腔」。
- 没有资料，我们卖少儿编程课，打给留过电话的家长，约他们来试听。
- 好了吗？

## 会发生什么

1. **收集企业信息**：只从对话里提取你说过的（企业、品牌、行业、产品、打给谁、目标、卖点、必须说、不能说），缺的合并成一次问完，能给选项的用选择卡。员工打电话要自称品牌，所以品牌一定会问。
2. **上传与准备**：按系统支持的格式和数量上传；重复材料会识别，超限会请你选择，不会擅自截断。
3. **确认卡**：列出系统给出的项目和费用。准备和上传不等于同意收费，你确认后才提交。
4. **生成中**：Skill 在对话里等待，只报系统给出的进度（例如“还在生成中，正在写话术”）。说“先别等了”会交还给你，之后再问进度时继续查同一个任务，不会重新创建。
5. **雇佣**：生成完成后选择计费方式（选项照系统原文）、确认品牌名和岗位名，附上员工的首句和截止时间；再确认一次后完成雇佣。超过截止时间需要重新生成并重新收费。

## 完成之后

- 新员工处于**培训中**，可以先网页试打一通，再按需[调优](adjust-agent.md)。
- 要给客户外呼，员工需要先在管理平台上岗，见[线索外呼](leads.md)。

## 出错时

- 同一步失败两次就停下，不换参数乱试，可以生成排障报告给客服。
- 余额不足不会自动充值或重复提交。
- 结果不确定时只查询原任务。
