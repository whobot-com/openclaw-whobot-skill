# 账号与余额

## 登录

不需要提前登录。第一次执行需要账号的操作时，Skill 会：

1. 完整展示系统返回的**隐私协议**和**用户协议**链接，以及新注册赠送与计费说明（新注册企业赠送 1000 万 token，数字员工正式上岗前不收坐席费等），说明继续即表示同意；
2. 请你看完后**直接回复**：还没给手机号时回复要登录的手机号；已给手机号时回复“继续”即用该号码登录，换号码就直接发新号码，不想登录就回复“不登录”；
3. 问短信验证码；
4. 登录成功后**自动接着做你刚才要做的事**，不需要再说一遍。

登录确认不弹选项卡，需要你手动回复。验证码只用于本次登录，Skill 不会复述验证码、Token 或完整手机号。

主动登录也可以，说“登录呼波特”即可。Skill 会先给你看协议和说明，再问手机号。

## 你可以这样说

- 换一个账号。
- 我想退出登录。
- 清除本机账号。
- 为什么显示已登录却不能用？
- 账户里还有多少钱？

## 退出与重置

退出、重置都会先给确认卡。换企业，或系统提示需要重置时，Skill 会停下当前操作，引导你重置后重新登录。员工和数据都在服务端，重置本机账号不影响它们。

## 查余额

Skill 会照系统返回说“企业账户总余额 X（含付费、赠费和信用额度）”，不估算、不换算。

## 凭据保存在哪

登录凭据由 `@whobot/cli` 保存在本机，Skill 不读取、不展示。排障时只会生成专门的排障报告，不包含 Token 和验证码。
