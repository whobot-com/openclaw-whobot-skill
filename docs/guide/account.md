# 账号与余额

## 登录

不需要提前登录。第一次执行需要账号的操作时，Skill 会：

1. 展示系统返回的**隐私协议**和**用户协议**链接，说明继续即表示同意；
2. 问你的手机号；
3. 问短信验证码；
4. 登录成功后**自动接着做你刚才要做的事**，不需要再说一遍。

验证码只用于本次登录，Skill 不会复述验证码、Token 或完整手机号。

主动登录也可以，说“登录呼波特”即可。

## 你可以这样说

- 换一个账号。
- 我想退出登录。
- 清除本机账号。
- 为什么显示已登录却不能用？
- 账户里还有多少钱？

## 退出与重置

退出、重置都会先给确认卡。换企业，或系统提示需要重置时，Skill 会停下当前操作，引导你重置后重新登录。员工和数据都在服务端，重置本机账号不影响它们。

## 查余额

Skill 会照系统返回说“企业账户总余额 X（含付费、赠费和信用额度）”，不估算、不换算。

## 凭据保存在哪

登录凭据由 `@whobot/cli` 保存在本机，Skill 不读取、不展示。排障时只会生成专门的排障报告，不包含 Token 和验证码。
