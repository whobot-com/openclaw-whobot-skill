# 调优、撤销与员工状态

## 什么员工能调

只有**培训中**、属于你本人、有生成记录的员工可以调优或撤销。刚雇佣好的员工就在培训中，可以马上调，不用等。已上岗员工的话术需要到[管理平台](https://work.whobot.com/)调整。

## 你可以这样说

- 把开场白改成“您好，我是丹丹口腔的小丹”。
- 客户问价格的时候，要报出准确价格：种植牙单颗一万两千八。
- 微信号换成我的。
- 这是新的价目表，补充进去。
- 看看有哪些版本。 / 回到上一版。

## 会发生什么

1. **整理要改什么**：只说“想调一下”时，Skill 会举一个贴合业务的例子请你指出哪里不满意；只说了哪里不对，会问“这种情况你希望她怎么说？”并给 2–3 个方向。
2. **原话不改**：你给的原句会一字不改地放进调优要求。
3. **确认卡**：调优和撤销都要确认，免费也要确认。
4. **结果**：分开说明新版本、逐条复测结果、已完成的原句、未完成和需要人工处理的条目。部分完成不会说成全部完成。

## 版本与撤销

“看看版本”会列出系统给出的版本号和变更；撤销前同样给确认卡。撤销后原来的版本依然保留，可以再调回来。

如果在确认前员工或材料的版本变了，Skill 会停下来重新准备，不会覆盖新版本。

## 员工状态

可以直接问“她现在在干什么”“能不能开工”，Skill 按系统返回的当前状态和可用操作回答。

| 你可以这样说 | 操作 |
|---|---|
| 上岗、正式上线、开始用 | 上岗 |
| 开工、开始打、恢复拨打 | 开工 |
| 先停一下、休息、暂停拨打 | 休息 |
| 回去调一调、下岗培训 | 下岗培训 |
| 不要了、解雇 | 解雇 |

- 每次调整都先给确认卡，你同意后才执行。解雇不能恢复；开工会开始真实拨打，并按所选计费方式产生费用。
- 某项操作当前不可用时（例如需要企业管理员操作），Skill 会转述原因，不会尝试。
- 上岗后员工处于暂停中，开工后才开始拨打。线路、企业认证或余额问题会按系统原文说明，并给出[管理平台](https://work.whobot.com/)入口。
